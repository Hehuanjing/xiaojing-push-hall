# 小晶推送馆

一个纯前端单页「今日热搜 + 个人推送」演示站点，只用 HTML + CSS + 原生 JavaScript 实现，无构建、无依赖、无 CDN，双击 `index.html` 即可运行。

## 功能

- **今日热搜**：内置 10 条热点，含排名徽章、分类标签、热度条与热度值，按日期种子生成热度并降序排列；点击（或聚焦后按 Enter）可把热点标题预填到发布表单。
- **发布推送**：标题（≤ 60 字）+ 正文（≤ 1000 字），提交后立即出现在列表顶部；空标题、空正文、全空均有独立提示。
- **查看与持久化**：列表按时间倒序展示标题、时间、正文；数据写入 `localStorage`，刷新或重开浏览器后仍在；存储不可用或写满时自动降级到内存并提示。
- **搜索筛选**：按标题与正文模糊匹配（忽略大小写），输入 120ms 防抖后实时过滤，显示「共 N 条 · 命中 M 条」，无结果时展示独立空态。
- **编辑**：每条推送可进入编辑态，回填表单、按钮变为「保存修改」，支持「取消编辑」；保存后更新原条目并保留点赞数。
- **点赞**：可点赞/取消点赞，计数与状态持久化，按钮展示计数。
- **删除**：二次确认后删除并同步存储。
- **响应式**：≤ 860px 自动切换为单列布局。

## 本地运行

直接双击打开 `index.html`，或在目录下起一个静态服务：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 数据结构

键名：`xjjg_posts`（`localStorage`），值为推送对象数组的 JSON：

```json
[
  {
    "id": 1763000000000001,
    "title": "标题",
    "body": "正文",
    "time": 1763000000000,
    "likes": 0,
    "liked": false
  }
]
```

- `id`：单调唯一整数（`Date.now() * 1000 + 自增序号`），避免同一毫秒内重复。
- `likes` / `liked`：点赞计数与当前点赞状态；v1.0 旧数据在读取时自动补齐（`likes: 0`、`liked: false`）。
